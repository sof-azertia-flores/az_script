# 编译器改进：进度与剩余工作

中文 | [English](STATUS.en.md)

本分支计划 28 个提交，修复审查发现的编译器问题，增加语言特性和运行时行号。为节省额度，工作在 C13 后暂停。完整进度表、剩余提交说明、用户决定和恢复步骤以英文版 [STATUS.en.md](STATUS.en.md) 为准；逐提交设计见 [DESIGN.md](DESIGN.md)，设计审查见 [COMPLETENESS.md](COMPLETENESS.md)。

## 已完成

C01–C13 已提交并推送：
- 带源码映射的诊断，支持多错误报告与警告；
- 十六进制运行时 ID；
- include 根目录与 `#pragma once`；
- 保留命名空间检查；
- 常数时间符号表；
- `SourceRules`；
- 名义类类型；
- 带类型的全局变量；
- `Base::m()` 调用；
- exec v10 与可选 `-g` 调试记录。

- C28 验证记录。

## 用户决定

- 调试信息需 `-g` 显式开启；
- 堆内存安全问题本轮不处理，仅写入文档；
- 函数 ID 仅改进文档与运行时提示；
- 允许更新 AGENTS 核心契约措辞。
