# 编译器改进：进度与剩余工作

中文 | [English](STATUS.en.md)

本分支计划 28 个提交，修复审查发现的编译器问题，增加语言特性和运行时行号。现已恢复工作并完成 C18；下一项是 C19。完整进度表、剩余提交说明、用户决定和恢复步骤以英文版 [STATUS.en.md](STATUS.en.md) 为准；逐提交设计见 [DESIGN.md](DESIGN.md)，设计审查见 [COMPLETENESS.md](COMPLETENESS.md)。

## 已完成

C01–C13 已提交并推送，C14–C18 已在本次续做中完成：
- 带源码映射的诊断，支持多错误报告与警告；
- 十六进制运行时 ID；
- include 根目录与 `#pragma once`；
- 保留命名空间检查；
- 常数时间符号表；
- `SourceRules`；
- 名义类类型；
- 带类型的全局变量；
- `Base::m()` 调用；
- exec v10 与可选 `-g` 调试记录；
- C14 脚本及原生调用栈、保留首个异常的清理、UTF-8 JNI 错误消息。Linux x86_64 的 V0–V3 均通过；
- C15 编译期及运行时仅允许布尔条件，拒绝不相容的相等比较，V0–V3 均通过。

- C16 int32 位运算和移位、预处理文本中的相邻符号判定、移位数量检查，V0–V3 均通过。

- C17 显式标量转换、严格且不受 locale 影响的十进制解析，使用 opcode 49，V0–V3 均通过。

- C18 返回值只允许精确类型或数值拓宽，数学库改为显式收窄，V0–V3 均通过。

## 用户决定

- 调试信息需 `-g` 显式开启；
- 堆内存安全问题本轮不处理，仅写入文档；
- 函数 ID 仅改进文档与运行时提示；
- 允许更新 AGENTS 核心契约措辞。
